🏦 Bank Management System
📌 Description

A simple Spring Boot REST API project to manage bank customers using MySQL and JPA.

⚙️ Technologies
Java
Spring Boot
Spring Data JPA
MySQL
Postman

👤 Customer Fields
Customer ID
Customer Name
Account Number
Balance
Email
Phone Number

🚀 API Endpoints
➕ Add Customer
POST /customer/add
📋 Get All Customers
GET /customer/getAll
🔍 Get Customer by ID
GET /customer/getById?id={id}
🔎 Get Customer by Name
GET /customer/getByName?name={name}
✏️ Update Customer
PUT /customer/update/{id}
❌ Delete Customer
DELETE /customer/delete/{id}
